## 律法夕惕者 Xitilex v1.0.1

修正多台電腦共用時的兩個問題。

### 🔧 修正

- **某台電腦只能用瀏覽器開**：原本缺少原生視窗元件（pywebview）時會不出聲地改用瀏覽器，
  而且瀏覽器模式的程式關掉分頁後仍留在背景，之後每次開都只會開瀏覽器。
  現在會跳提示說明原因（執行一次 `安裝.exe` 即可補裝）；背景已有瀏覽器模式的程式時，會請它結束、改用視窗開啟。
- **Claude「工具」裡看不到自己的 skill**：可用工具清單存在各台電腦本機，原本只查一次、查失敗就一直停在舊結果。
  現在這台沒查過、上次失敗或超過三天，開程式時會自動在背景重查。
  （帳號裡的 skill 與雲端連接器需要命令列 Claude 已登入：開一般 PowerShell 執行 `claude` → `/login`；
  新電腦已登入仍看不到時，在 PowerShell 開著 `claude` 幾分鐘讓它把帳號 skill 下載到這台。）

### 🆕 新增

- **診斷報告** `data/diag/<電腦名稱>.json`：每台電腦開程式時記下用視窗或瀏覽器開、原因、元件與 Claude 登入狀態、帳號 skill 的同步狀態、查到的 skill 與連接器。
  跟著雲端硬碟同步，某台出狀況時在另一台就看得到。只記狀態，不記案件內容。

### 下載

| 檔案 | 適用 |
|---|---|

從 v1.0.0 更新：用新版檔案覆蓋程式資料夾即可（`config.json` 與 `data/` 裡的個人資料不在壓縮檔內，不會被蓋掉）。
需要 Python 3.10 以上；程式沒有付費數位簽章，第一次執行若出現「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。
完整步驟見 [README](https://github.com/ulysses5976/Xitilex#下載與安裝)。

## Xitilex v1.0.1

Fixes two problems when the same program folder is shared by several computers.

### 🔧 Fixes

- **A computer only opens Xitilex in the browser**: when the native-window component (pywebview) was missing, the app silently fell back
  to the browser, and the browser-mode server kept running in the background, so every later launch opened the browser again.
  It now explains why (run `安裝.exe` once on that computer), and a background browser-mode server hands over to the native window.
- **Your own skills missing from Claude's "Tools" dialog**: the tool list is cached per computer and was probed only once.
  It is now re-checked in the background when missing, when the last check failed, or after three days.
  (Account skills and cloud connectors need the Claude Code CLI to be logged in: run `claude` → `/login` in a normal PowerShell;
  on a new computer, keep an interactive `claude` session open for a few minutes so it downloads your account skills.)

### 🆕 New

- **Diagnostics report** `data/diag/<computer name>.json`: launch mode and reason, component and Claude login status, account-skill sync status, detected skills and connectors.
  Synced with Google Drive so you can check a problem computer from another one. No case content is recorded.

### Download

| File | For |

Updating from v1.0.0: copy the new files over the program folder (your `config.json` and `data/` are not in the zip).
