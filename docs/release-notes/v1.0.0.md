## 律法夕惕者 Xitilex v1.0.0

第一個公開版本。律師的案件工作台：直接讀你電腦或 Google 雲端硬碟裡的案件資料夾，
把狀態、庭期、期限、待辦整理成一個工作台，並可以在案件裡直接吩咐 Claude Code 讀卷、整理、更新進度。

### 🆕 主要功能

- **今日總覽**：開程式先看今天的庭期與期限、已逾期的待辦、未來七天（標出國定假日）與新收文書。
- **案件頁**：最近期限與下一次庭期一眼可見；待辦、庭期、案件資訊、案件摘要都能直接修改；卷宗檔案用預設程式開啟。
- **法定期間計算**：民事、非訟、家事、消債、刑事、行政共 19 種常用期間，處理寄存／公示送達、在途期間、遇假日順延，一鍵加入待辦。
- **新收文書提醒**：案件資料夾出現新文件時提醒；一鍵請 Claude 讀判決或通知書，把庭期與期限寫進案件卡。
- **利益衝突檢查**：開新案時比對所有案件的當事人、對造與案件卡內文。
- **Google 日曆同步**、**庭期月曆**、**待辦總覽**、多分頁多視窗、墨綠／宣紙等多種配色。

## Xitilex v1.0.0

First public release. A case workbench for lawyers in Taiwan: it reads the case folders you already keep on your
computer or Google Drive, turns status, hearings, deadlines and to-dos into one workbench, and lets you ask
Claude Code to read and organize a case right inside it. The interface is in Traditional Chinese.

### 🆕 Highlights

- **Today** overview: today's hearings and deadlines, overdue to-dos, the next seven days with public holidays, new documents.
- **Case page** with inline editing of to-dos, hearings, case details and summary.
- **Statutory deadline calculator** — 19 common periods with service rules, travel days and holiday roll-over.
- **New-document alerts** — one click asks Claude to read a new judgment and record the deadline.
- **Conflict check** when opening a new case.
- Google Calendar sync, hearing calendar, to-do overview, tabs and multiple windows, several themes.

### Download

| File | For |
|---|---|
| `Xitilex-v1.0.0-windows.zip` | Windows 10/11: unzip and run `安裝.exe` (the installer) |

Requires Python 3.10+. The app is not code-signed; if Windows shows "Windows protected your PC", click
**More info → Run anyway**. See the [README](https://github.com/ulysses5976/Xitilex/blob/main/README.en.md#download--install).
